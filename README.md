# 🎓 Placement Portal

A full-stack Placement Portal built using **HTML, CSS, JavaScript, Node.js, and Express**.  
It helps manage job postings, applications, and tracking in a simple and efficient way.

---

## 🚀 Live Demo

👉 Frontend: https://gshagun16.github.io/placement-portal/
👉 GitHub Repo: https://github.com/gshagun16/placement-portal

---

## ✨ Features

- ➕ Add new job postings  
- 📋 View all available jobs  
- 📝 Apply to jobs easily  
- 📊 Track application status  
- ❌ Delete job postings  
- 🔍 Simple and clean UI for better usability
