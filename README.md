# 🚀 Placement Portal

A modern **Placement Portal Web App** where users can register, explore job opportunities, and apply seamlessly.

🔗 **Live Demo:**
https://gshagun16.github.io/placement-portal/

---

# 📌 Features

### 👤 Authentication

* Register new users
* Login / Logout system

### 💼 Job Management

* Add new job postings
* View all jobs
* Edit job details
* Delete jobs

### 📥 Applications

* Apply for jobs
* Withdraw application
* Track applied jobs

### 🔍 Search & Filter

* Search by job title or company
* Filter by company

### 🎨 UI/UX

* Clean modern interface
* Dark mode 🌙
* Smooth animations ✨
* Responsive layout

---

# 🛠️ Tech Stack

* **HTML5**
* **CSS3**
* **JavaScript (Vanilla JS)**
* **LocalStorage (for data persistence)**

---

# ⚙️ How It Works

* All data (users, jobs, applications) is stored in **browser localStorage**
* No backend required (frontend-only project)
* Fast and easy to run on any browser

---

# 🚀 How to Run Locally

1. Download or clone the repository
2. Open `index.html` in your browser
